# CAD Assist: плагин для КОМПАС-3D

CAD Assist — проект плагина для САПР на базе **КОМПАС-3D**. Плагин предназначен для связи CAD-модели с внешними инженерными и IoT-данными: устройствами, датчиками, зонами размещения, статусами оборудования и отчётами.

## Цель проекта

Реализовать прикладной модуль для КОМПАС-3D, который позволяет пользователю:

- выбирать элементы 3D-модели;
- привязывать к ним устройства или инженерные объекты;
- просматривать состояние связанного оборудования;
- сохранять связи между CAD-объектами и внешними сущностями;
- формировать отчёты по модели.

## Базовая САПР

Выбрана САПР: **КОМПАС-3D**.

Причины выбора:

- распространённость в российских инженерных и учебных проектах;
- поддержка 3D-моделирования и конструкторской документации;
- наличие возможностей автоматизации через API и внешние модули;
- удобная база для демонстрации интеграции CAD-модели с внешней информационной системой.

## Основной сценарий

1. Пользователь открывает модель в КОМПАС-3D.
2. Запускает плагин CAD Assist.
3. Авторизуется во внешней системе, если это требуется.
4. Выбирает объект модели или точку размещения.
5. Привязывает выбранный CAD-объект к устройству или инженерной сущности.
6. Плагин сохраняет связь в метаданных модели или во внешнем JSON-файле.
7. При повторном открытии модели плагин восстанавливает связи и показывает актуальные статусы.

## MVP

Минимальная версия должна включать:

- окно подключения к backend;
- получение списка устройств или инженерных объектов;
- выбор объекта в КОМПАС-3D;
- создание и удаление привязки;
- хранение привязок в JSON sidecar-файле;
- просмотр карточки связанного объекта;
- цветовую индикацию статуса;
- экспорт CSV-отчёта.
